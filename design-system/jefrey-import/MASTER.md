# Design System Master File — JefRey Import

**Projeto:** JefRey Import — importadora de peças automotivas
**Categoria:** Catálogo B2B/B2C orientado a cotação (não é e-commerce com checkout)
**Padrão de página:** Hero-Centric + Feature-Rich Showcase (baseado no briefing do cliente)
**Estilo:** Trust & Authority com energia automotiva (não é glassmorphism/3D/dark OLED — mantém leitura séria e limpa)

## Paleta de Cores

| Papel | Hex | Uso |
|---|---|---|
| Primária (fundo escuro) | `#0A2540` | Header, hero, footer, rodapé |
| Primária (interativa) | `#0066CC` | Links, ícones, elementos secundários |
| Destaque/CTA | `#FF6600` | Botões de ação ("Solicitar Orçamento", CTAs) |
| Fundo | `#F5F7FA` | Fundo geral das seções |
| Fundo cartão | `#FFFFFF` | Cards, formulários |
| Texto/apoio | `#2C3E50` | Texto secundário, rodapé |
| Disponível | `#27AE60` | Badge "Em estoque" |
| Sob consulta | `#F39C12` | Badge "Sob consulta" |
| Destrutivo | `#E63946` | Erros de formulário |

## Tipografia

- **Títulos:** Montserrat (600–700)
- **Corpo:** Inter (400–500)
- Base 16px, escala 12/14/16/18/24/32/48

## Tom de voz

Português do Brasil, profissional mas acessível. Vocabulário: "peças automotivas", "compatibilidade", "veículo", "instalação" — nunca "componentes eletrônicos" genéricos.

## Categorias de peças

Faróis, Lanternas, Peças de Motor, Lâmpadas, Multimídia, Tunning/Acessórios

## Elementos de confiança obrigatórios

Selo "Importação Direta", selo de garantia, selo de compatibilidade verificada, selo de entrega nacional, CNPJ no rodapé, lista de veículos compatíveis em toda peça.

## Escopo desta entrega (Fase 1 — MVP)

Home, Catálogo (/pecas) com filtros, Página de peça (/pecas/[slug]), Orçamento (/orcamento), Contato (/contato), botão WhatsApp flutuante, Política de Privacidade, Termos de Uso, 404 customizada. SEO básico (metadata, sitemap, robots, schema Organization/Product/BreadcrumbList). Fases 2/3 (busca por veículo em cascata dedicada, carrinho de orçamento múltiplo, depoimentos, FAQ, blog) ficam para próxima iteração.
